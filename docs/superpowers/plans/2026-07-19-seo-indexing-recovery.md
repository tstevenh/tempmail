# SEO Indexing Recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the automatic Turnstile wall, restore five valuable English blog URLs with DataForSEO-informed articles, consolidate public URLs on the HTTPS apex hostname, and verify Cloudflare is not challenging Googlebot.

**Architecture:** Keep the existing signed inbox-session API and Durable Object WebSocket security unchanged, but make verification an explicit inline inbox action for browsers without a session. Add a source-controlled English blog registry that KV posts can override, normalize only the two production hostnames at the beginning of the Worker fetch handler, and treat Cloudflare Security Events as a read-only evidence-gathering step before changing any WAF rule.

**Tech Stack:** Cloudflare Workers, JavaScript ES modules, Wrangler, KV, D1, Durable Objects, Turnstile, Node test runner, DataForSEO v3 API.

```js
async function getPostsIndex(env, locale = "en") {
  const fallback = locale === "en"
    ? englishBlogPosts()
    : localizedBlogPosts(locale).map((p) => ({ slug: p.slug, title: p.title, desc: p.desc, date: p.date }));
  try {
    const raw = await env.TEMPMAIL_KV.get(postsIndexKey(locale));
    const stored = raw ? JSON.parse(raw) : [];
    if (Array.isArray(stored) && stored.length) {
      const storedSlugs = new Set(stored.map((p) => typeof p === "string" ? p : p.slug).filter(Boolean));
      return [...stored, ...fallback.filter((p) => !storedSlugs.has(p.slug))];
    }
  } catch {}
  return fallback;
}

async function getPost(env, slug, locale = "en") {
  if (locale !== "en") return localizedBlogPost(locale, slug);
  try {
    const raw = await env.TEMPMAIL_KV.get(postKey(locale, slug));
    if (raw) return JSON.parse(raw);
  } catch {}
  return englishBlogPost(slug);
}
```

```js
if (/noindex/i.test(response.headers.get("x-robots-tag") || "")) throw new Error(`${url}: x-robots-tag contains noindex`);
if (/<meta name="robots" content="[^"]*noindex/i.test(html)) throw new Error(`${url}: meta robots contains noindex`);
const canonical = html.match(/<link rel="canonical" href="([^"]+)"/i)?.[1];
if (canonical !== url) throw new Error(`${url}: canonical is ${canonical || "missing"}`);
```

Run with bounded concurrency of 10 so verification is fast without flooding the Worker.
